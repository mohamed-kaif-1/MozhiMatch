# Privacy model

The editor supplies practice questions. The UI must state before AI submission that both language versions leave the device for the configured Google service. Source-kind attestation and consent are required, while hosted allowlisting also restricts inputs to exact original samples. Private upcoming exam drafts are outside this free-tier deployment's permitted data scope.

App source/results/decisions are in memory. Reset, source edit and refresh clear data as specified by the state model. Locale alone persists. Operator code stays only in memory. No content is written to application logs, analytics, cookies, database or server cache. Do not add a crash-replay service that captures the editor.

The hosting platform and AI provider may process/retain telemetry or content under their terms. In-memory app design cannot erase upstream copies. Avoid claiming on-device processing, zero retention or guaranteed secrecy. A future confidential-paper mode requires separately assessed provider agreements and controls.

The reviewer intentionally copies an issue list to the clipboard. It includes selected source excerpts and manual actions. Clipboard retention is controlled by the operating system, and the app cannot withdraw already copied text. Show the export preview before Copy. Evaluation files use original synthetic fixtures and can be committed after secret checks, while arbitrary real user submissions cannot be used as test data without permission.
