# Evaluation plan

Development fixtures are in `src/fixtures/development.json`. Holdout inputs and labels (`holdout-inputs.json`, `holdout-expected.json`) are in `src/fixtures/`. Their English–Tamil texts are original synthetic authored items, so the hosted app can use development examples without redistributing exam pages.

Benchmark conditions are rules-only, human side-by-side checklist, the strong generic same-model prompt, the app workflow and a direct translation QA service if Tamil is available. A missing competitor test must be marked NOT RUN, not assumed inferior. Use identical item text, allowed context and source markings. Never give the app labels or context absent from comparators.

Heldout has 10 items comprising four material differences, three clean controls, two ambiguous proper-name/idiom cases and one label/count structural case. Our labels are proposed bilingual expectations and require a fluent reviewer to sign off before calling the result a gold standard. Remove the labels from model input. Do not tune against holdout. If the implementation agent reads it before freezing the prompt, author a fresh holdout for a valid final claim.

Record item-level material recall, clean false alerts, ambiguous escalation, structural result, false clear count, evidence-valid ratio and input-to-verified-action time. Gate is 4/4 material hits, 2/2 uncertainty escalations, zero false clears on material/structural issues, at most one alert on three clean controls, and valid evidence for every displayed comparison. To establish advantage, require 25% lower median verified completion time across three counterbalanced small sessions with comparable errors, or one extra correctly grounded material finding with equal time and no added errors. Repeat-use familiarity and small sample size must be disclosed.

Write raw evaluation outcomes to a local file with explicit fixture IDs, model, prompt hash and settings. These original fixture results can be committed after checking for secrets. Operational logs of arbitrary source text remain prohibited. All results initially are NOT RUN. Template is evaluation-results-template.csv. Set thresholds before opening responses. A failed honest benchmark is a decision result, not an invitation to invent favourable figures.
