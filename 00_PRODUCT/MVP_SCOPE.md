# MVP scope

P0 consists of one workbench, paired structured text, rule findings, one server-side semantic comparison, exact evidence display, decisions, locale switch, original examples and plain-text copy. Process at most ten items per request. Keep raw text and derivative comparison text distinct.

P1, only after the gate and deployment smoke, includes additional original examples and an issue-only filter. P2 includes PDF/OCR, CSV import, glossary administration, history, accounts, teacher collaboration, automatic translation/correction, speech and analytics. P2 is deferred.

The public deployment starts in rules-only mode. Hosted live analysis accepts an exact server-side demo item set and private operator code. Local authorized testing can accept custom public/owned items after explicit consent. This is one app with configuration modes, not separate products.

If time slips, reduce custom item editing to one item and keep deterministic fixture loading, evidence and manual decision. Keep both locales and one unknown case. Drop export beyond clipboard, decorative interactions and batch convenience. The product still must demonstrate its semantic comparison on honest inputs. See the canonical contracts for limits and error behaviour.
