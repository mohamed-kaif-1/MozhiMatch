# Timeboxed schedule

All times are elapsed from project start. Pair schedule is conditional on event permission. Source registry is tasks.json. Each lane is sequential and non-overlapping. First five hours use 15-minute blocks with the first five minutes for dependency/input inspection, next five for the smallest implementation/check and last five for verification/handoff. Break blocks remain rest.
