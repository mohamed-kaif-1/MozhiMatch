# Master implementation plan

This is an elapsed 24-hour reference sprint, not 48 uninterrupted working hours. The task registry accounts for each lane's complete window, including meals, breaks, integration and contingency. The exact event listing is solo. Use the pair plan only when allowed; otherwise use SOLO_IMPLEMENTATION_PLAN.md. Starting at late evening on 18 November cannot create a fresh 24-hour event window. The observed deadline is 19 November 13:30 IST.

Critical path is event/contract confirmation → provider/evidence feasibility → gate → analyze route → source-grounded UI → final evaluation → deployment verification → submission. Frontend tokens/editor/locale can proceed independently while the proof runs. A gate failure stops semantic-product expansion while the team investigates whether the same narrow workflow can pass.
