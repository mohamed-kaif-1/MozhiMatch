# Team handoff protocol

Handoff occurs after a coherent commit, not an untracked workspace dump. Include branch/commit, changed files, schema version, exact command outputs, fixture exercised, unresolved errors and the next dependency. Do not paste keys, codes or private question text into the handoff.

Kaif reviews Aasim's UI integration against canonical examples at IC2 and IC3. Aasim reviews Kaif's normal/error responses through actual controls. If blocked, send the smallest input and expected contract, then work on independent locale/layout/test tasks. Do not change someone else's owned files to bypass a missing contract.

Integration cadence is after interface freeze, after first source-grounded result, after both locales, before feature freeze and before release. Reserve a 15–30 minute slot for each merge/test. If a merge fails, inspect conflicts and preserve both intended behaviours. Re-run affected tests before committing. No force push or broad clean is part of normal recovery.

Use HANDOFF.md for current state and PHASE_COMPLETION_TEMPLATE.md for phase evidence. A blocked task keeps its status BLOCKED with the concrete dependency, while the next independent task can proceed. Breaks and buffers in the schedule are deliberate, not unassigned missing work.
