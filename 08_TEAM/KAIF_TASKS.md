# Kaif execution lane

This is the accountable integrator lane. Read TEAM_ALLOCATION.md and INTEGRATION_CONTRACT.md first. The actual event is solo unless explicit permission changes the contribution boundary. Use the solo roadmap when permission is unresolved.

Own tasks K01–K58 in the task registry. Every task lists exact source files, dependencies, acceptance checks, recovery and its Antigravity prompt. See [the detailed breakdown](../07_IMPLEMENTATION/DETAILED_TASK_BREAKDOWN.md) and [schedule](../07_IMPLEMENTATION/MINUTE_LEVEL_SCHEDULE.md).

Own package/lock/contracts, rules, evidence, provider/access, route tests, deployment and final submission. Coordinate reducer actions before UI integration. Never hide a failed semantic gate with fixture output.

Before each handoff record branch/commit, changed files, actual command results, exercised fixture and the next dependency. Integrate at IC1–IC6. Use buffer blocks for confirmed failures and leave rest blocks as rest. If blocked, preserve the last working state and work only on an independent module whose prerequisites are met.
