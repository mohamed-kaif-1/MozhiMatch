# Judge questions

| Question | Defensible response |
|---|---|
| Why not paste both versions into a general model? | We ran the same inputs against a strong prompt and measured verified review effort. Show actual results. If the comparison ties, acknowledge that differentiation remains unproven |
| What does the AI add beyond labels/counts? | Meaning comparison for unchanged structure. The semantic gate isolates negation/entity/qualifier and option-meaning changes, with separate rules results |
| Can a valid quote still support a wrong conclusion? | Yes. Exact evidence establishes traceability. Human labels and reviewer decisions evaluate correctness. We reject missing coverage, but cannot certify semantic truth |
| How original is this? | Translation QA and assessment translation review already exist. The proposed advantage is a compact Tamil–English fixed-option workflow, conditional on the comparison result |
| Where does source text go? | It remains in app memory and, after consent in AI mode, is sent through the server to Google. This free demo uses original/public practice content |
| Why no PDF upload? | The initial workflow uses explicit pairs to test the meaning-review claim. Layout extraction would add a separate unvalidated problem |
| Is this production-ready? | It is a measured hackathon prototype with stated input limits, failure handling and a small evaluation. Broader content, confidential drafts and institution adoption need separate validation |
| What if the API fails? | Rules and manual review remain visible. Replay is labelled. The app never replaces failure with invented live output |

Only use the first answer after the relevant comparison has run. Record an untested result as pending. A model's self-reported confidence is not used in the product.
