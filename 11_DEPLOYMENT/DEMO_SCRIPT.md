| 1:25–1:45 | Measured evaluation table | Show actual sample counts, false alerts, evidence validity and total verified review time against the strongest tested workflow |
| 1:45–2:00 | Locale switch and live URL/repo | Tamil UI preserves the source and decisions. This prototype covers small explicitly paired practice items, with cloud processing disclosed |

Use measured timing rather than promising a five-second result. If no comparative advantage was demonstrated, say so and revise the claim. Avoid declaring global novelty or guaranteed exam correctness. The script is proposed until rehearsed with actual app behaviour.
