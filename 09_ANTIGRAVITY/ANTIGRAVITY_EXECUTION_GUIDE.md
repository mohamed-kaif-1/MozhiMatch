# Execution policy

For each selected prompt, read root AGENTS.md, the listed canonical files and HANDOFF.md. Inspect actual source and Git before editing. Confirm prerequisites through observable files/checks. A prior written claim that a phase completed is insufficient when its code/test state does not match.

Implement only the cohesive current milestone, keep contract/owner boundaries, run relevant checks and update HANDOFF.md with changed files, exact commands/results, remaining blockers and the next dependency. A failed test can be fixed within scope. Do not stop for routine reversible choices or dependency installs already specified by the plan.

Pause for a concept change, destructive Git/broad deletion, an unapproved paid dependency, missing real credentials needed for live work or external-impact actions without an identified account/authorisation. Before asking, complete independent local work and make the pending action concrete. The concept gate can stop further feature work on actual evidence; it does not require approval for every passing phase.

Keep mocked API tests separate from explicit live evaluation. Never write EXPECTED/PASS metrics as executed results. Read-only comparison research does not authorise sending messages or submissions to external audiences. Final event entry uses the entrant's account and observed required fields.
