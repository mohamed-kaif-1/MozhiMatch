# Release checklist

- [ ] G0 event prompt, solo entry and registration are confirmed for this entrant.
- [ ] Root contracts agree with runtime Zod definitions and fixture examples.
- [ ] typecheck, lint, test, test:e2e and build commands recorded with actual exit codes.
- [ ] No live API use in automatic test suites.
- [ ] Exact item coverage and source-span tests pass.
- [ ] No secret/private draft in repo, build assets, evaluation files or logs.
- [ ] Both UI locales tested at required widths and with keyboard.
- [ ] Hosted origin, private operator code and exact demo allowlist verified.
- [ ] AI outage shows unavailable and rules/manual mode.
- [ ] Live evaluation table shows real counts/timing, provenance and model/prompt version.
- [ ] Public repo README explains setup, limitations and content provenance.
- [ ] Live URL checked signed out from an independent tab/device where possible.
- [ ] Two-minute demo practised with an ambiguous input and outage path.
- [ ] Submission fields completed and success state recorded before deadline.

Initial state is NOT RUN for application checks. Feasibility and deployment readiness remain conditional. Mark a checkbox only when the implementation run produces corresponding evidence.
